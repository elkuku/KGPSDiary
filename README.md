# KGPSDiary

A GPS diary: save waypoints with a title, a description, a category, tags, photos and a visit
date, and see them on a Mapbox map in the Android app and on the web.

| Folder | What |
|---|---|
| [`app/`](app) | Android app (Kotlin, Jetpack Compose) |
| [`web/`](web) | Symfony web app and API, PostgreSQL |
| [`docs/`](docs/developers/index.md) | Developer docs |

See [PLAN.md](PLAN.md) for the project plan and milestones.
